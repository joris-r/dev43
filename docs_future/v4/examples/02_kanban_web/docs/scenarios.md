# Scenarios

## First card

The board is empty.

- The user types "write tests" and clicks "Add".
- The card appears in To do, and the field is empty again.
- They click "→" twice: the card is in Done, with no "→" button.

## Clearing done work

The board holds "write tests" in Done.

- The user clicks "×" on it.
- The board is empty.
- They reload the page: the board is still empty.
